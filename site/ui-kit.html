Buttons & actions

Orange is the single primary action. Dark green is for confirmations inside flows, white for secondary choices, and red only for destructive work. Every target is at least 44px tall — 48px on customer and admin, 56px on rider.

14 · Rules

Accessibility rules

WCAG 2.2 AA is the floor, not a stretch goal. These checks apply to every screen, every state and every new component added to this kit.

  • Contrast. Normal text ≥ 4.5:1; large text and UI boundaries ≥ 3:1. Never white on #F28C28.
  • Focus. A 3px visible ring with 3px offset on every interactive element. Orange on dark, green on light. Never remove it.
  • Targets. 48×48px on customer and admin; 56×56px on rider. Spacing between targets ≥ 8px.
  • Status. Colour + icon + word. Test in greyscale before shipping.
  • Forms. Visible labels, aria-invalid, aria-describedby and text errors. Never placeholder-only.
  • Landmarks. One h1 per page, skip link first, semantic header, nav, main, footer.
  • Live updates. Toasts and result counts use aria-live="polite"; errors use role="alert".
  • Motion. prefers-reduced-motion disables smooth scroll, shimmer and transitions.
  • Keyboard. Tabs, dialogs, menus and the PIN pad all work without a pointer. Escape returns focus.
  • Offline honesty. A blocked completion is announced as blocked, never as delivered.
