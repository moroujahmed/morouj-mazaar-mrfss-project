Four portals

Built around the person holding the screen.

Every interface shares the same tokens and components, but each one changes density, type size and action priority to match its job. Nothing is colour-only, and no critical action depends on hover.

Shared palette

Deep green, flame orange, honest neutrals.

White text on the primary green measures 11.67:1. Green text on the orange action fill measures 4.76:1. Orange is never used as body text on white; the darker orange token is used when orange must be text.
