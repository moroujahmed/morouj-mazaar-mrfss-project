Accessibility rules

  • WCAG 2.2 AA; normal text ≥ 4.5:1, large text ≥ 3:1.
  • Every page starts with a skip link and contains one h1.
  • Focus is always visible: 2 px #173F35 ring, 2 px offset.
  • Icon-only controls have an aria-label.
  • Body text ≥ 16 px; critical prices and CTAs ≥ 18 px semibold.
  • Never white text on #F28C28 at any size (2.32:1); use #102E27.
  • Maps provide attribution and a text fallback.
  • prefers-reduced-motion removes non-essential motion.
